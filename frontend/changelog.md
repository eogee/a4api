# a4api v0.3.2

## 新增

### 应用内「问题反馈」：直达开发者邮箱

- 点击页脚「问题反馈」打开反馈弹窗，Bug 报告 / 功能需求两类，支持**附带截图**（最多 10 张、单张 ≤1MB）与选填联系方式
- 反馈先落本地库留档（feedback / feedback_images 表），再尽力**直接邮件送达开发者邮箱**，截图以附件随行；`emailed` 标志记录送达结果，网络不通时仅入库、内容不丢
- 自动采集环境信息（版本 / 系统 / 运行模式），可选附带应用日志尾部，免去手写复现环境
- SMTP 凭据存本地私有文件（不入库）；未配置时反馈仅入库留档，不影响提交

### 「版本与更新」弹窗

- 点击页脚版本号弹出「版本与更新」：当前版本、完整更新日志（随包内嵌 changelog）、**检查更新**按钮与 GitHub Releases 直链
- 更新日志由发布流程自动同步（`release_body.md` → 随包内嵌），应用内展示与 Release 页保持一致
- 弹窗固定尺寸、内容区内部滚动，任何窗口大小下保持垂直居中

## 改进

- **全新 logo**：应用图标、网页 favicon 与页脚标识全面换新
- **GitHub Issue 结构化模板**：Bug 报告 / 功能需求表单化；与应用内反馈互补——应用内提交会自动带齐环境信息
- 代理状态接口响应带上应用版本号，便于排查远端代理场景的版本错配
